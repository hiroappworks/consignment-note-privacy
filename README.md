# 委託販売ノート プライバシーポリシー

「委託販売ノート」のApp Store Connect登録用プライバシーポリシーを、外部トラッカーのない静的HTML/CSSで公開するための専用サイトです。

## ファイル

- `index.html`：日本語プライバシーポリシー本文
- `styles.css`：レスポンシブ表示、ダークモード対応のスタイル

JavaScript、Cookie、Analytics、外部フォント、外部フレームワークは使用していません。

## GitHub Pages

GitHub Pagesは、`main`ブランチのリポジトリルート（`/ (root)`）から配信します。公開後のURLは次の形式です。

`https://<GitHubユーザー名>.github.io/consignment-note-privacy/`

## 更新時の注意

アプリの外部サービス、送信イベント、データ保存範囲を変更する場合は、本文の実装との整合性を確認してから更新してください。RevenueCat APIキー、PostHog APIキー、`.env`、証明書、アプリ本体のソースコード、実データはこのリポジトリへ追加しません。
